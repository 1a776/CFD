# 项目概要

本项目围绕 [`pdf/training_examples_incomp.pdf`](pdf/training_examples_incomp.pdf) 中的五个不可压 CFD 数值测试题目展开，目标是逐步完成对应方程的有限体积离散、OpenFOAM 求解器实现、案例计算和结果分析。

## 1. 对流方程

研究二维线性对流方程的显式有限体积离散，包含正弦波平移和复杂轮廓固体旋转算例。
- 离散过程
- 详细研究报告
- 具体数据

## 2. 扩散方程

研究扩散方程的显式有限体积离散，包含间断初值和连续函数两个精度测试算例。

## 3. 对流扩散方程

研究同时包含输运和扩散作用的对流扩散方程，比较不同网格和格式下的误差与收敛表现。

## 4. Poisson 方程

研究 Poisson 方程的空间离散和数值求解，通过给定解析解检验计算精度。

## 5. Navier-Stokes 方程

研究不可压 Navier-Stokes 方程的有限体积求解流程，重点包括投影法和 PISO 方法。
