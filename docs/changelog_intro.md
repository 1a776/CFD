# 改动记录模板

以后每次完成一轮较大的改动，在 `docs/changelog.md` 的最上方新增一条记录。
最新记录放在最前面，旧记录继续保留。

格式如下：

```markdown
# 记录：<commit编号>｜<时间>｜<本轮改动名称>

## 实现功能

详细说明本轮实现了什么功能：

- 完成了什么；
- 支持哪些案例、网格、格式或分辨率；
- 生成了哪些数据、图片、报告或脚本；
- 用户现在可以怎样使用；
- 本轮改动达到什么结果。

## 改动代码

详细列出修改、新增或删除的文件，并说明每个文件具体改了什么：

- `path/to/file`
  - 修改了哪个函数、类、配置项或章节；
  - 代码逻辑发生了什么变化；
  - 这个修改解决了什么问题；
  - 与其他文件如何配合。

## 遇到 Bug

如果没有 Bug，写：

本轮未遇到阻塞性 Bug。

如果遇到 Bug，按照下面格式记录：

### Bug 1：<Bug名称>

- **现象：** 出现了什么错误、异常结果或运行失败；
- **原因：** Bug 为什么发生；
- **修复：** 修改了哪个文件、哪部分代码，采用了什么解决方法；
- **验证：** 使用什么命令或检查确认已经修复。

### Bug 2：<Bug名称>

- **现象：**
- **原因：**
- **修复：**
- **验证：**
```

示例：

```markdown
# 记录：a1b2c3d｜2026-08-25 20:30｜完善第一题验证报告

## 实现功能

完善第一题正弦波平移和固体旋转的数值验证报告，补充四边形、三角形、
一阶迎风和线性迎风实验的误差、收敛阶、振幅、CFL 和旋转轮廓分析。
报告中的图片直接显示，并增加图号和正文引用。

## 改动代码

- `report/01_advection_equation/report.md`
  - 增加实验结果表；
  - 增加图 1 至图 45；
  - 增加图片尺寸、图注和正文交叉引用；
  - 增加不同网格和插值格式的现象分析。
- `report/01_advection_equation/evidence_index.md`
  - 更新实验数据、图片和报告证据路径。

## 遇到 Bug

### Bug 1：图片路径缺失

- **现象：** 报告中部分图片无法显示；
- **原因：** 报告目录调整后，相对路径层级没有同步修改；
- **修复：** 更新 `report/01_advection_equation/report.md` 中的图片相对路径；
- **验证：** 检查全部图片路径，确认缺失图片数量为 `0`。
```
