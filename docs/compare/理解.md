  第4题建议采用下面这套基准配置。

  - 网格分辨率统一取 `N=10,20,40,80`。
  - 四边形网格和三角形网格分别进行收敛分析，不能把两种网格混在同一组收敛阶中。
  - `N` 表示每条边方向的网格单元数。四边形网格大约有 `N^2` 个单元，三角形网格大约有 `2N^2` 个单元。
  - 计算区域为 `[0,1]^2`。
  - 解析解为：

    $$
    \phi_{\mathrm{exact}}(x,y)=\cos(\pi x)\cos(\pi y)
    $$

  - 源项为：

    $$
    \omega(x,y)=-2\pi^2\cos(\pi x)\cos(\pi y)
    $$

  - 四条边均采用 Dirichlet 边界，由解析解提供边界值。
  - `system/fvSchemes` 使用：

    ```foam
    gradSchemes
    {
        default Gauss linear;
    }

    laplacianSchemes
    {
        default        none;
        laplacian(phi) Gauss linear corrected;
    }

    snGradSchemes
    {
        default corrected;
    }
    ```

  - `Gauss` 表示使用有限体积面通量求和。
  - `linear` 表示面值或面系数线性插值。
  - `corrected` 表示对非正交网格加入非正交修正，三角形网格尤其需要保留。
  - `system/fvSolution` 初始建议使用 `GAMG`：

    ```foam
    solvers
    {
        phi
        {
            solver          GAMG;
            tolerance       1e-12;
            relTol          0;
            smoother        GaussSeidel;
        }
    }
    ```

  - `tolerance 1e-12` 要求线性方程组求解得足够精确。
  - `relTol 0` 表示不能因为相对残差达到某个较松的比例就提前停止。
  - `GAMG` 适合这类 Poisson 型椭圆方程；如果某个三角形案例不稳定，也可以改用 `PCG` 或 `smoothSolver` 做对照。
  - `nNonOrthogonalCorrectors` 初始取 `2`。四边形规则网格上修正通常很小，三角形网格上需要通过重复组装和求解减小非正交修正误差。
  - 这个参数是工程实现约定，不是原题指定值。报告中必须写明实际使用的数值。

  第4题的实际求解链条是：

  $$
  \nabla^2\phi=\omega
  \longrightarrow
  \sum_f(\nabla\phi)_f\cdot\mathbf S_{cf}=V_c\omega_c
  \longrightarrow
  \texttt{fvm::laplacian(phi)==omega}
  \longrightarrow
  \mathbf A\boldsymbol{\phi}=\mathbf b
  \longrightarrow
  \texttt{phiEqn.solve()}
  $$

  求解器代码负责调用 `fvm::laplacian(phi)` 和 `solve()`；网格、边界、Laplacian 格式和线性求解器参数由 cases 中的 `constant/polyMesh`、`0/phi`、`system/fvSchemes` 和 `system/fvSolution` 决定。

  其中 `N` 和离散格式直接影响网格离散误差，`tolerance` 和 `relTol` 主要控制代数求解误差。为了让收敛阶反映空间离散精度，线性求解误差应明显小于网格离散误差。

  收敛阶使用相邻分辨率的误差计算：

  $$
  p=
  \frac{\log(E_1/E_2)}
  {\log\left[(N_{e,2}/N_{e,1})^{1/2}\right]}
  $$

  其中 `E1` 和 `E2` 必须来自同一种网格、同一种误差范数和相邻两层分辨率。第一题、第二题、第三题和第四题都存在类似的实现参数约定，但第四题没有 CFL 和时间步，重点转移到了 `fvSchemes`、`fvSolution` 和非正交修正控制。

## 第三题病态误差数据归档与修正

第三题第一个正弦波对流-扩散案例在 `mu=1`、`t=1` 时的解析振幅为：

$$
\exp(-8\pi^2)=5.12250228\times10^{-35}
$$

原后处理使用终态解析解范数作为相对误差分母，因此四边形结果出现约 `10^17` 量级、三角形结果出现约 `10^21` 量级的归一化误差。这是极小分母造成的病态指标，不是求解器发散；原始运行数据和图片已完整保存到 `data/03_advection_diffusion_equation/pathological_relative_error/` 和 `figures/03_advection_diffusion_equation/pathological_relative_error/`。

修正后没有修改求解器、网格或物理参数，只在 `scripts/common/advection_tools.py` 增加绝对误差和相对于初始场的归一化误差，在 `scripts/common/postprocess_case.py` 中写入新字段，并在 `scripts/common/study_analysis.py` 中让第三题正弦波使用 `initialNormalizedL1/L2/Linf` 计算收敛阶和绘图。旧的 `normalizedL1/L2/Linf` 继续保留为历史诊断字段，`relativeErrorValid=false` 明确标记其不适合本案例的终态相对误差判断。
