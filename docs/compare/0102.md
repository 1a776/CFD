# 01 和 02 算例对比：一阶迎风与二阶迎风

本文比较两个正弦波线性对流算例：

| 算例 | 路径 | 空间对流格式 |
|---|---|---|
| 01 | `cases/01_advection_equation/01_sine_wave_quad/` | `Gauss upwind` |
| 02 | `cases/01_advection_equation/02_sine_wave_quad_linearUpwind/` | `Gauss linearUpwind grad(T)` |

两个算例求解的是同一个问题：

$$\frac{\partial \phi}{\partial t}+\nabla\cdot(\boldsymbol{u}\phi)=0$$

初始条件、速度、定义域、边界和时间推进都相同：

| 项目 | 设置 |
|---|---|
| 初值 | $\phi_0(x,y)=\sin 2\pi(x+y)$ |
| 速度 | $(u,v)=(1,1)$ |
| 定义域 | $[0,1]\times[0,1]$ |
| 网格 | $20\times20$ 四边形网格，共 400 个 cell |
| 边界 | x、y 方向周期边界 |
| 终止时间 | $t=1.0$ |
| CFL | `maxCo 0.2` |
| 时间步数 | 200 |
| 时间推进 | 显式前向 Euler |

因此，这两个算例的主要差别就是 `system/fvSchemes` 里 `div(phi,T)` 的面值插值方式。

## 1. 代码里哪里体现差别

01 算例：

```foam
divSchemes
{
    default         none;
    div(phi,T)      Gauss upwind;
}
```

02 算例：

```foam
gradSchemes
{
    default         Gauss linear;
    grad(T)         Gauss linear;
}

divSchemes
{
    default         none;
    div(phi,T)      Gauss linearUpwind grad(T);
}
```

求解器源码里调用的是同一句：

```cpp
fvc::div(phi, T, "div(phi,T)")
```

这句代码不会把格式写死。OpenFOAM 会根据 `fvSchemes` 中的名字 `"div(phi,T)"` 查找具体离散格式。所以 01 和 02 不需要改 C++ 求解器，只改 case 的 `system/fvSchemes` 就能比较不同插值格式。

## 2. 后处理结果对比

当前结果来自：

```text
data/01_advection_equation/cases/01_sine_wave_quad/N20/summary.json
data/01_advection_equation/cases/02_sine_wave_quad_linearUpwind/N20/summary.json
```

主要数值如下：

| 指标 | 01 一阶迎风 | 02 二阶迎风 |
|---|---:|---:|
| `normalizedL1` | 0.7980079419 | 0.4362010019 |
| `normalizedL2` | 0.7950221146 | 0.4338468604 |
| `normalizedLinf` | 0.7947571291 | 0.4335153736 |
| `initialAmplitude` | 1.0 | 1.0 |
| `finalAmplitude` | 0.2052428709 | 1.4175374335 |
| `massChange` | $1.11\times10^{-19}$ | $1.11\times10^{-19}$ |
| `maxCo` | 0.2 | 0.2 |
| `timeSteps` | 200 | 200 |

这个表非常关键：02 的误差比 01 小，但 02 的振幅超过了初始振幅。这两件事可以同时发生。

原因是：

- 01 一阶迎风很稳定、很耗散，会把波峰和波谷快速抹平；
- 02 二阶迎风耗散更小，整体波形可能更接近精确解，所以 L1/L2/Linf 误差更小；
- 但是 02 使用梯度外推，格式本身不保证有界，因此局部会产生超调和欠调。

## 3. 为什么一阶迎风振幅下降

一阶迎风的面值只取上游单元值：

$$T_f=T_{\mathrm{upwind}}$$

它的直观含义是：信息从上游单元搬到下游单元，面值不会向外 extrapolate。

对正弦波这种光滑波形，一阶迎风最典型的问题不是爆炸，而是数值耗散太强。它会不断削弱波峰、填平波谷，所以 `amplitude_history.png` 里振幅向下走。

当前 01 的时间历史中：

```text
t = 0.005: amplitude = 0.990211303259
t = 1.000: amplitude = 0.205242870870
```

也就是说，初始振幅 1 经过一圈周期输运后，只剩约 0.205。这个结果说明它很稳，但也说明它把正弦波抹得很厉害。

## 4. 为什么二阶迎风振幅会超过 1

二阶迎风不是简单地取上游单元值，而是从上游单元向面中心做梯度外推：

$$T_f=T_{\mathrm{upwind}}+\nabla T_{\mathrm{upwind}}\cdot(\boldsymbol{x}_f-\boldsymbol{x}_{\mathrm{upwind}})$$

这里的 `grad(T)` 就来自 02 算例里的：

```foam
grad(T)         Gauss linear;
```

这个外推能减少一阶迎风的耗散，让波形不那么快被抹平。但它有一个重要代价：外推出来的面值不一定落在相邻单元值之间。

因此，即使初始场满足：

$$-1\le T\le 1$$

二阶迎风推进之后也可能出现：

$$T_{\max}>1,\quad T_{\min}<-1$$

当前 02 的时间历史中：

```text
t = 0.005: amplitude = 0.999760453540
t = 0.020: amplitude = 1.005188459470
t = 1.000: amplitude = 1.417537433530
```

这就是你看到 `amplitude_history.png` 往上走的原因：二阶迎风在当前网格和时间推进下产生了超调/欠调，最大值和最小值被拉开了。

## 5. 为什么二阶迎风误差更小但振幅更大

这件事容易混淆。误差小和有界不是同一个性质。

01 一阶迎风：

- 优点：比较稳，振幅不会乱长；
- 缺点：数值耗散强，波峰波谷被严重抹平；
- 结果：振幅从 1 降到 0.205，L1 误差约 0.798。

02 二阶迎风：

- 优点：耗散小，能保留更多正弦波形；
- 缺点：无界外推会造成局部超调和欠调；
- 结果：振幅从 1 增到 1.418，但 L1 误差约 0.436，反而比 01 小。

所以 02 并不是“完全坏了”。它在当前结果里比 01 更接近精确解，但同时暴露了无界格式的风险。

## 6. 为什么这不是质量守恒问题

两个算例的 `massChange` 都是：

```text
1.1102230246251566e-19
```

这已经接近机器精度，可以认为总量守恒很好。

同时两个算例的 `maxAbsResidualIntegral` 也都很小：

```text
01: 2.99239799606e-17
02: 4.59701721134e-17
```

这说明周期边界和有限体积守恒结构基本正常。

因此，02 振幅上升不是因为“质量凭空产生”，而是因为局部的数值分布发生了超调和欠调。总积分可以守恒，但最大值和最小值仍然可以越界。

一句话：

```text
守恒控制的是总量；
有界控制的是最大值和最小值；
精度控制的是离精确解有多近。
```

这三件事相关，但不是同一件事。

## 7. 每张图应该怎么读

### 7.1 `field_comparison.png`

01 中数值场会比精确解更平，颜色范围会变浅。这说明一阶迎风耗散强。

02 中数值场可能保留更多波峰波谷，但误差图会在峰谷附近出现更明显的局部误差。这说明二阶迎风减少耗散的同时产生了超调/欠调。

### 7.2 `diagonal_profile.png`

01 的曲线会被压扁，峰值低于精确解，谷值高于精确解。

02 的曲线可能更接近正弦形状，但局部会超过精确解峰值或低过精确解谷值。

### 7.3 `amplitude_history.png`

01 向下：说明数值耗散不断削弱波形。

02 向上：说明二阶外推带来了超调/欠调，最大值和最小值被拉开。

### 7.4 `cfl_history.png`

两个算例都保持 `maxCo = 0.2`。所以这里的差别不是 CFL 不一致造成的，而是空间离散格式不同造成的。

## 8. 这个现象是否正常

正常，但需要正确理解。

对当前粗网格、显式 Euler、无界二阶迎风格式来说，02 出现振幅超过 1 是可以预期的数值现象。它不是物理增长，也不是周期边界失效，而是 `linearUpwind` 梯度外推不保证最大值原理。

如果目标是做“光滑正弦波精度测试”，二阶迎风可能比一阶迎风误差更小。

如果目标是做“强间断、方波、不能越界的标量输运”，无界二阶迎风就不够稳，后面应考虑限制器格式，例如 `limitedLinear`、`vanLeer`、`MUSCL` 或其他 TVD/NVD 类格式。

## 9. 后续建议

下一步可以做三类比较：

1. 固定格式，细化网格，看 02 的超调是否随网格加密减弱。
2. 固定网格，降低 CFL，看显式时间推进对振幅增长的影响。
3. 加入限制器格式，对比 `upwind`、`linearUpwind`、`limitedLinear` 的误差、振幅和有界性。

判断一个格式时，不要只看一张图。至少同时看：

| 指标 | 用途 |
|---|---|
| L1/L2/Linf 误差 | 判断整体精度 |
| `amplitude_history.png` | 判断耗散或超调 |
| `massChange` | 判断守恒 |
| `cfl_history.png` | 判断时间步是否一致 |
| `diagonal_profile.png` | 判断相位误差、幅值误差和局部越界 |

当前结论是：

```text
01 一阶迎风：有界、稳定、耗散强、误差大。
02 二阶迎风：误差更小、耗散更弱、但无界，出现明显超调/欠调。
```
