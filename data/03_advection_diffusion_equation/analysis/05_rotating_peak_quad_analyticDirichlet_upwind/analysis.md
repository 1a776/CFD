# 05_rotating_peak_quad_analyticDirichlet_upwind 网格收敛性分析

本研究使用第三题第二个旋转尖峰对流-扩散算例，比较不同 均匀结构化四边形 网格分辨率。
所有网格使用相同的区域 [-1,1]^2、速度 U=(-y,x)、扩散系数 ε=1e-3、外边界 fixedValue 0、全显式对流-扩散稳定时间步，并从 tau=0 旋转到 tau=2π。

$$p = \frac{\log(E_N/E_{2N})}{\log(2)}$$

其中 $E_N$ 是分辨率为 $N$ 时的误差，$p$ 是观察收敛阶。

## 边界和时间说明

本案例用 OpenFOAM 计算时间 tau 表示从初始尖峰出发后的旋转时间，终止时间为 tau=2π。解析解中的扩散年龄为 t0+tau，其中 t0=π/2。
当前实现先采用 fixedValue 0 外边界。由于尖峰在区域内部旋转，边界解析值为指数小量，该处理用于先验证内部对流-扩散求解链路。

## 结论

L1 误差从 `1.40607172e+00` 变为 `9.25832748e-01`。
L1 观察收敛阶依次为 `0.247625, 0.355222`。
