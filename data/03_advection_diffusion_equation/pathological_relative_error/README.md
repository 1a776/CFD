# 第三题病态误差历史归档

本目录保存第三题第一个正弦波对流-扩散算例在误差指标修正前生成的完整结果。归档时间为 2026-08-27，包含四边形和三角形网格的 `N=10,20,40,80` 数据、汇总表、运行清单和分析图片。

原始后处理使用解析解范数归一化：

$$
E_{\mathrm{rel}}=\frac{\| \phi_{\mathrm{num}}-\phi_{\mathrm{exact}}\|}{\|\phi_{\mathrm{exact}}\|}
$$

本算例取 `mu=1`、`t=1`，解析正弦波的振幅为：

$$
\exp(-8\pi^2)=5.1225\times 10^{-35}
$$

因此解析解范数接近双精度舍入量级，原归一化指标会被极小分母放大到 `10^17` 至 `10^21`。这些数值是历史结果，保留用于追溯和比较，不用于判断本算例的收敛性，也不表示求解器发散。

目录内容：

- `cases/01_sine_wave_quad_upwind/`：四边形网格各 `N` 的原始单案例数据；
- `cases/02_sine_wave_tri_upwind/`：三角形网格各 `N` 的原始单案例数据；
- `01_sine_wave_quad_upwind/`：四边形网格的原始汇总 CSV、运行清单和分析文字；
- `02_sine_wave_tri_upwind/`：三角形网格的原始汇总 CSV、运行清单和分析文字；
- `figures/`：对应的原始收敛图和单案例诊断图。

修正后的正常结果仍写入：

`data/03_advection_diffusion_equation/` 和 `figures/03_advection_diffusion_equation/`

修正后的主收敛指标使用相对于初始场的归一化误差，同时保留旧的解析解归一化误差字段作诊断。
