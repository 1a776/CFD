# 03_sine_wave_tri_linearUpwind 网格收敛性分析

本研究使用周期正弦波线性对流算例，比较不同 三角形棱柱 网格分辨率。
所有网格使用相同的初始函数、速度、周期边界、CFL 和终止时间。

$$p = \frac{\log(E_N/E_{2N})}{\log(2)}$$

其中 $E_N$ 是分辨率为 $N$ 时的误差，$p$ 是观察收敛阶。

## 结论

L1 误差从 `2.98257438e-01` 变为 `2.00968360e-02`。
L1 观察收敛阶依次为 `1.498497, 1.305666, 1.087355`。
